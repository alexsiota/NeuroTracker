NeuroTracker is a mobile application developed in Android Studio using Kotlin and Jetpack Compose, designed to simulate a cognitive training environment inspired by neurotechnology systems.

The application allows users to perform different cognitive tests (such as reaction time, memory, and attention exercises), track their performance, and analyze their progress over time. Although it does not use real EEG hardware, it simulates brain-related metrics to provide a more engaging and realistic experience.

🎯 Main Features
User authentication (login and registration)
Multiple cognitive tests (reaction time, memory, attention, etc.)
Performance tracking with stored results
Historical data and progress visualization
Simulated cognitive/EEG indicators
Simple and intuitive UI built with Jetpack Compose
🧠 Purpose of the Project

This project was developed as a final degree project (TFC) with the goal of:

Applying mobile development concepts using modern Android tools
Designing a structured and scalable application (MVVM approach)
Working with local databases (SQLite / Room)
Simulating real-world cognitive training systems
🛠️ Technologies Used
Kotlin
Jetpack Compose
Room (SQLite abstraction)
MVVM architecture
Material 3 design components
